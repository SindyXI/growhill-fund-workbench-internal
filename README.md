# Growhill fund research workbench

This repository hosts the encrypted static files for an internal research workbench. The published files contain ciphertext only. The access code is shared separately with authorized colleagues.

This material is for internal research. It is not approved for client distribution.

The site is built from the maintained workbench source. Rebuilds use fresh random encryption salts and nonces. GitHub Pages serves the encrypted files; decryption happens in the browser.
